# Telgram-News

نحوه اجرای این پروژه روی سرور (VPS)

دانلود پروژه:
git clone https://github.com/amirh55/Telgram-News.git
cd Telegram-News

نصب پیش نیاز ها و اجرا:
chmod +x setup.sh
./setup.sh

python brain.py

گرفتن Gemini API Key:
راهنمای گام‌به‌گام دریافت کلید API جمی‌نای
گام ۱: ورود به Google AI Studio
۱. مرورگر خود را باز کرده و به وب‌سایت aistudio.google.com بروید.
۲. با حساب کاربری گوگل (Gmail) خود وارد شوید (Sign in). اگر از قبل وارد شده باشید، مستقیم به داشبورد هدایت می‌شوید.

گام ۲: درخواست کلید API
۱. در منوی سمت چپ یا بالای صفحه، دکمه‌ای به نام "Get API key" (دریافت کلید API) را خواهید دید. روی آن کلیک کنید.
۲. در صفحهٔ جدید، روی دکمهٔ آبی‌رنگ "Create API key" کلیک کنید.

گام ۳: انتخاب پروژه و تولید کلید
۱. در این مرحله یک پنجره کوچک باز می‌شود. گوگل از شما می‌خواهد که کلید را برای یک پروژه بسازید.
۲. اگر برای اولین بار است که این کار را می‌کنید، گزینهٔ "Create API key in new project" (ساخت کلید در پروژه جدید) را انتخاب کنید تا گوگل خودش یک پروژه استاندارد برای شما ایجاد کند.
۳. چند ثانیه منتظر بمانید تا سیستم پروژه را بسازد و کلید شما را تولید کند.

گام ۴: کپی کردن و ذخیره امن
۱. حالا یک کد طولانی ترکیبی از حروف و اعداد به شما نمایش داده می‌شود. روی دکمهٔ Copy کلیک کنید.
۲. مهم: این کلید را همین حالا در یک فایل متنی در کامپیوتر خود ذخیره کنید، چون لایه امنیتی گوگل به شما اجازه نمی‌دهد بعداً دوباره این کلید را به طور کامل تماشا کنید (اگر گم شود، باید یک کلید جدید بسازید).
